# 시아아빠의 AI작업실

플랫폼 · 웹툰 · 영상 · 음악 모음: https://tkooya-09.github.io/

## 작품 관리

`assets/app/site.js`의 `ITEMS` 배열에서 작품을 추가·수정합니다. 공개 저장소 자동 수집은 사용하지 않습니다. 음악 파일은 `assets/music/`에 두고 `audio`, `lyrics` 항목을 등록합니다. 공개 가능한 자료만 커밋하세요. 비공개 표시나 화면 숨김만으로 GitHub의 공개 파일을 보호할 수는 없습니다.

## 관리자 로그인

https://tkooya-09.github.io/admin.html

1. 최초 한 번 이메일과 로그인 비밀번호를 등록하고 이메일을 인증합니다.
2. 로그인한 뒤 별도로 전달된 기존 관리자 암호로 최초 소유자 연결을 완료합니다.
3. 연결 완료 시 기존 공통 암호는 폐기되고 재등록이 닫힙니다. 이후에는 등록한 계정만 방명록·챌린지 게시글을 관리합니다.

가입 자체에는 관리 권한이 없습니다. 인증 메일 발송은 Supabase의 이메일 발송 설정과 한도에 따릅니다. 기본 메일 서비스가 수신자를 제한하면 사용자 지정 SMTP 또는 허용된 계정 설정이 필요합니다. 관리 계정은 아직 생성되지 않았으며 소유자가 직접 위 단계를 완료해야 합니다.

방명록과 게시글은 숨김·복원이 가능하며, 챌린지 글을 수정할 수 있습니다. 공개 작품·음악 파일 편집은 GitHub에서 진행합니다. 토큰을 브라우저 저장소에 보관하지 않으며, 새로고침 시 다시 로그인합니다. 10분 미사용 또는 로그인 후 30분이 지나면 재로그인합니다.

## 검증

```sh
node --test tests/security/*.test.mjs
```

`tests/security/admin-auth.sql`은 관리자 DB 변경과 함께 트랜잭션 안에서 실행하고 반드시 롤백하는 검증용입니다. 운영 계정을 만들지 않습니다. GitHub Actions의 `Security checks`가 프런트엔드·방명록 검사를 수행합니다.

변경 이력과 제한 사항은 `supabase/SECURITY.md`를 참고하세요.
