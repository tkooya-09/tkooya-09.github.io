# 전명구의 AI 작업실

바이브코딩 플랫폼 · 웹툰 · 영상 작업 모음 홈페이지 (https://tkooya-09.github.io/)

## 작업 추가·수정 방법
1. 이 저장소에서 `index.html`을 열고 연필(✏️) 버튼을 누릅니다.
2. 맨 위 `▼▼▼ 여기만 고치면 됩니다 ▼▼▼` 부분의 `ITEMS` 목록에서 `{ ... }` 한 덩어리를 복사해 붙여 넣고 내용만 바꿉니다.
3. `Commit changes`를 누르면 1~2분 뒤 홈페이지에 반영됩니다.

| 항목 | 설명 |
|---|---|
| type | `platform`(플랫폼) / `webtoon`(웹툰) / `video`(영상) |
| title, desc | 제목, 한 줄 소개 |
| url | 열기 버튼 주소 (배포 주소) |
| repo | GitHub 저장소 이름 — 적으면 링크·날짜가 자동으로 채워짐 |
| youtube | 유튜브 주소 (영상만) — 썸네일·재생 창 자동 생성 |
| episodes | 웹툰 회차 목록 `{ no, title, url }` |
| status | 운영 중 / 교육용 / 정비 중 / 보관 등 |
| open | `공개` 또는 `내부용` (내부용이면 링크를 숨김) |

## GitHub 저장소 자동 등록
- `SITE.github.auto: true`이면 공개 저장소를 자동으로 불러와 카드로 보여 줍니다.
- 일부만 보이게 하려면 `topic: 'portfolio'`로 바꾸고, 보여 줄 저장소에만 `portfolio` 꼬리표(Topics)를 답니다.
- 빼고 싶은 저장소는 `exclude`에 이름을 적습니다.
- GitHub 접속이 막힌 곳(일부 내부망)에서는 직접 입력한 목록만 보입니다.
